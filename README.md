# Profile Card UI/UX Design

A responsive profile card design built using HTML5, CSS3, and Font Awesome icons. This layout uses relative CSS units (`vh` and `vw`) to deliver a smooth, responsive experience across different display sizes.

---

## 🚀 Features

* **Responsive Layout:** Designed with viewport height (`vh`) and viewport width (`vw`) for dynamic scaling.
* **Flexbox Structure:** Clean, three-column design layout (left accent border, central branding text, and right profile card).
* **Overlap Profile Design:** Absolute positioning and transform properties create an overlapping circular profile avatar effect.
* **Font Awesome Integration:** Styled social media icons (Facebook, Instagram, LinkedIn, Behance, GitHub) and interaction statistics (Likes, Comments, Shares).
* **CSS Gradients:** Custom linear gradient effects applied to icon elements.

---

## 🛠️ Built With

* **HTML5:** Semantic structural markup.
* **CSS3:** Flexbox layout, absolute positioning, CSS transform tricks, CSS gradients, and responsive viewport units.
* **Font Awesome (v7.3.1):** Scalable vector icons for social media and user metrics.
